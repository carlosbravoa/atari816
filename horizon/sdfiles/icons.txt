# icons.txt - the Horizon desktop icons, 32 x 32 pixels, 8 bpp (palette: tools/mkpalette.py)
#
# Converted by tools/mkicons.py into a binary (1024 bytes per icon, row-major, one byte per
# pixel, icons in file order) and a ca65 include (ICO_<NAME> = index, ICO_COUNT).
#
# Format
#   #...               a comment (whole line, or after whitespace); blank lines are ignored
#   color C N          maps the single character C to palette index N (0-255). Before the
#                      first icon it is global; after an "icon" line it applies to that icon
#                      only (and may override a global one). '#' and space can not be used.
#   icon NAME          starts an icon: optional "color" lines, then exactly 32 rows of exactly
#                      32 characters, each a mapped character
#
# Index 255 is transparent ('.'): never use it as a colour (it is also a grey).
#
# House style: a 1-pixel black outline, a lighter highlight along the inside top/left edge,
# a darker edge along the bottom/right, and a 1-pixel drop shadow in colour 15 ('S') one
# pixel right and down. Keep the art within about 30 x 30; the label is drawn below the icon.
# LINK and LOADED are overlays drawn on top of another icon (bottom-left / top-right corner).
#
# The palette: 0-15 UI colours, 16-231 the colour cube 16 + 36r + 6g + b (r, g, b 0-5 =
# 0, 51, ... 255), 232-255 greys 8 .. 238 in steps of 10.
