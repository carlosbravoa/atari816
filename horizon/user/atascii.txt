; Atari ROM data): the shapes follow the ATASCII code chart (box lines, blocks, triangles, card
; suits, arrows), drawn here pixel by pixel. The letters, digits and punctuation are not here:
; tools/mkatascii.py takes them from Horizon's own console font (kernel/font8x12.txt).
; Each glyph: "char XX" (hex ATASCII code), then 8 rows of 8 columns, '#' = ink, '.' = paper.
